## 👁️‍🗨️ Overview
**The Quantum Relic Heart** is a purely code-driven, mathematically generated biomechanical organism. It is not a pre-rendered video or a static 3D model. It is a living, breathing artifact rendered in real-time on your browser.

Blending **Cyber-Feudal** aesthetics with raw computational power, this piece reacts to user interaction by shifting its quantum states, audio telemetry, and vector gravity fields.

## ⚙️ Interactive Mechanics
- **3D Rotation:** Drag across the viewport to inspect the geometric core beneath the binary tissue.
- **Quantum Shock (Tachycardia):** `[CLICK AND HOLD]` to reverse the gravity vectors. The shell shatters, the BPM skyrockets, and the core synthesizes a chaotic glitch audio frequency.

## 🧠 Technical Architecture
Built without external libraries, utilizing pure mathematical projection and native browser APIs:
* **Audio Synthesis:** `Web Audio API` (ADSR Envelopes, Dynamics Compressor, Sine/Triangle Oscillators).
* **3D Algebraic Surfaces:** The outer shell is generated using the continuous surface equation `(x^2 + 9/4 y^2 + z^2 - 1)^3 - x^2 z^3 - ...`
* **Performance (LOD):** Engineered for steady 60FPS using State Caching and Level of Detail (LOD) optimization for 3800+ independent particles.
* **Neural Plexus:** Real-time proximity calculation for rendering interconnecting energy nodes.
